# 🎙️ VocabVibe — AI Voice Vocabulary Tutor

A lightweight, interactive web prototype designed to help users master advanced vocabulary through real-time voice interactions, pronunciation evaluation, and spaced repetition flashcards.

---

## ✨ Features

* **🗣️ Real-time Speech Recognition:** Practice speaking vocabulary words and get instant feedback on accuracy and pronunciation.
* **🔊 Natural Voice Synthesis:** Hear natural pronunciations and context sentences powered by browser voice engines (`SpeechSynthesis`).
* **🎴 Dynamic Flashcards:** Interactive card deck featuring word definitions, phonetic guides, synonyms, and example sentences.
* **📈 Mastery & XP Tracking:** Live progress tracking with experience points (XP) and daily streak counts.
* **🎛️ Interactive Simulation Mode:** Built-in fallback controls to test all features smoothly without requiring microphone access.
